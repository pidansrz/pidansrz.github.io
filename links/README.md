# links/ —— 荐读（好文收藏）

这里放你收藏的**别人的好文章**：原文链接 + 来源署名 + 你的一句话评语 + 全文存档。

和 `drafts/` 完全独立：不进文章列表、不进归档、不算进文章数，只出现在「荐读」页和站内搜索里。

## 怎么加一条

在 `links/` 下新建一个 `.md`，文件名建议 `日期-拼音slug.md`（和 `drafts/` 一样）：

```markdown
---
title: 文章的原标题
source: 来源媒体/公众号名
author: 作者名（可留空）
url: https://原文链接
date: 2026-10-20
tags: 调查, 媒体
note: 你的一句话评语——我为什么收藏它
---

这里开始粘贴全文（Markdown）。
支持 ## 小标题、- 列表、> 引用、**加粗**、[链接](url)、![图片](images/xxx.jpg)。
```

## 字段说明

| 字段 | 必填 | 说明 |
|---|---|---|
| `title` | ✅ | 原文标题 |
| `source` | ✅ | 来源（如「人物」「三联生活周刊」），会显示在条目上 |
| `author` | | 作者 |
| `url` | ✅ | 原文链接，页面顶部会显示，点击跳原站 |
| `date` | ✅ | 收录日期，用于排序 |
| `tags` | | 逗号分隔，如 `调查, 译介` |
| `note` | ✅ | 你的一句话评语，列表页直接显示 |

## 注意事项

- **文件名以 `_` 开头的文件、`README.md` 不会被收录**（可以当模板/草稿放着）。
- **仓库是 public**：写进这里的全文，任何人在 GitHub 上都看得到。
  只收藏已获授权、或明确声明可转载的文章；拿不准的就只写链接 + 评语，不放全文。
- 原文链接会失效。每条务必写清 `source` 与 `title`，即使链接挂了，信息本身还在。

## 改完之后

```bash
node tools/build-links.js     # 或 node tools/build-all.js（推荐，会跑全部）
```

生成 `js/links-data.js`、`js/links-text.js` 和 `links/<id>.html`，然后提交推送即可。
