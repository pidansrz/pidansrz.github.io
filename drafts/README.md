# drafts/ — 文章草稿目录（批量导入用）

把你整理好的文章放进这个文件夹，每篇一个 `.md` 文件，然后跑一条命令，
全部文章就会**自动按日期倒序**进入 `js/data.js`。

```bash
node tools/import-posts.js --dry-run    # 先预览，不写文件
node tools/import-posts.js --replace    # 确认无误后真导入
```

> 本文件（`README.md`）和以 `_` 开头的文件不会被导入，可以放心放这里。

---

## 一、文件名怎么起

**推荐：日期写在前头**，脚本会自动识别，不用在文件里再写一遍日期。

```
2024-05-12-楼下那家修鞋摊.md     ✓ 推荐
2024-05-12.md                    ✓ 也行（标题就写在文件里）
我的文章.md                       △ 能用，但日期会取「文件修改时间」
```

日期写在文件里也可以（见下面的 front-matter），两者都有时**以文件里的为准**。

---

## 二、文件里怎么写

开头一段 `---` 包起来的是**文章信息**（可省略，脚本会自动补）；后面是正文，用 Markdown。

```markdown
---
title: 楼下那家修鞋摊
date: 2024-05-12
excerpt: 一句话摘要，不写就自动取正文开头。
cover: images/shoe-repair-stall.jpg
coverAlt: 街角修鞋摊，旧工具箱与木凳
id: shoe-repair-stall
draft: false
---

## 一双一双地修

他修鞋有个习惯：先问你「打算还穿多久」。

> 我们习惯用「效率」衡量一切，可有些东西的价值恰恰在于它不肯快。

- 打算再穿两年，他就用线缝
- 打算穿到明年，他就用胶粘
```

### 文章信息字段（全部可选）

| 字段 | 说明 |
|---|---|
| `title` | 标题。不写就取文件名去掉日期前缀 |
| `date` | 日期 `YYYY-MM-DD`。不写则取文件名前缀，再没有就用文件修改时间 |
| `excerpt` | 摘要。不写则自动截取正文前 110 字 |
| `cover` | 头图路径。不写则自动找 `images/` 里同名图片 |
| `coverAlt` | 图片说明（无障碍 + 配图时显示在图下方） |
| `id` | 文章地址 `post.html?id=xxx` 用的标识。**中文标题建议手动指定一个英文 id**，链接更短更好看 |
| `draft` | 写 `true` 则这篇**不导入**（想先攒着不发布时用） |

## 三、正文支持的 Markdown

| 写法 | 效果 |
|---|---|
| `## 小标题` | 二级标题（`###` `####` 同理） |
| 普通段落 | 空一行分段 |
| `> 引用` | 引用块 |
| `- 条目` | 无序列表（有序列表写 `1.` 也支持） |
| `**加粗**` / `*斜体*` | 强调 |
| `[文字](网址)` | 链接 |
| `![说明](images/a.jpg)` | 插入图片 |
| `` `代码` `` | 行内代码 |
| `---` | 分隔线 |

首段会自动排版成「导语」（字号略大），所以**第一段写好一点**。

---

## 四、头图怎么自动配上

不用一个个填路径。把图片丢进 `images/`，**文件名和文章文件名去掉日期后一样**就行：

```
drafts/2024-05-12-楼下那家修鞋摊.md
images/shoe-repair-stall.jpg       ← 手动指定 id 时用 id 命名
```

支持 `.jpg` `.jpeg` `.png` `.webp` `.gif`。配不上也无所谓，会显示占位封面，不破版。

## 五、常见情况

**Q：想先攒着、这篇先不发？**
文件头写 `draft: true`，或者把文件名改成 `_` 开头（如 `_草稿.md`）。

**Q：导入时提示「有 N 篇文章不在 drafts 中」？**
那是 `data.js` 里现有的文章（比如现在那篇示例《楼下那家修鞋摊》）。两个选择：

- `node tools/import-posts.js --replace` —— 用 drafts 覆盖，那些文章会被清掉
- `node tools/import-posts.js --keep-existing` —— 保留它们，和 drafts 合并

**Q：改坏了怎么办？**
每次导入都会自动把上一版存成 `js/data.backup.js`，直接改名覆盖回去即可。

**Q：导入完就完事了吗？**
还差一步——订阅源是静态文件，不会自己更新：

```bash
node tools/build-feed.js
```
